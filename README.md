# Тарелка и штанга

Android-приложение для подопечной тренера: дневник питания с подсчётом КБЖУ по тексту, вода, шаги и расход калорий, тренировки по подходам с таймером отдыха, база знаний по упражнениям, прогресс в графиках и отчёт тренеру.

## Как получить APK

Каждый раз, когда в ветку `main` попадают изменения, GitHub сам собирает приложение (вкладка **Actions**, около 2 минут). Готовый файл `tarelka.apk` появляется в разделе **Releases**.

## Как установить

1. Скачайте `tarelka.apk` и перешлите на телефон, например в Telegram.
2. Откройте файл на телефоне. Android попросит разрешить установку из этого приложения — разрешите.
3. Новые версии ставятся поверх старой, записи сохраняются.

## Тренер и подопечная

- Тренер ставит это же приложение, в «Профиле» нажимает «Я тренер — войти» и создаёт аккаунт (почта и пароль).
- На экране «Мои подопечные» тренер добавляет подопечную и получает код из 6 символов.
- Подопечная вводит код в «Профиле» → «Тренер». После этого дневник, вес, замеры, шаги и тренировки синхронизируются в обе стороны, а программа от тренера появляется у неё сама.
- Данные хранятся в Firebase (проект `trener-bca36`). Правила доступа — в файле `firestore.rules`: их нужно один раз вставить в Firebase → Firestore Database → Rules → Publish.

## Где что лежит

- `app/src/main/assets/` — само приложение:
  - `index.html`, `styles.css`, `app.js` — экраны и логика;
  - `foods.js` и `parser.js` — база продуктов (около 450 позиций) и разбор фраз вроде «гречка 150 г, 2 яйца»;
  - `knowledge.js` — упражнения, статьи и шаблоны программ.
- `app/src/main/java/ru/tarelka/app/` — обёртка Android: кнопка «Назад», отправка отчёта, датчик шагов (`StepTracker`, `StepWorker`), вибрация таймера, сканер штрихкодов и запросы к базе продуктов Open Food Facts.
- Firebase SDK скачивается при сборке в `app/src/main/assets/vendor/`.
- `app/tarelka.keystore` — ключ подписи. Не удаляйте: без него новые версии не встанут поверх старой.

Записи хранятся на телефоне. Раз в неделю делайте резервную копию: «Профиль» → «Резервная копия».

# Тарелка и штанга

Android-приложение для клиентки: дневник питания с подсчётом КБЖУ по тексту, вода, вес, замеры, программа тренировок и отчёт тренеру.

## Как получить APK

Каждый раз, когда в ветку `main` попадают изменения, GitHub сам собирает приложение (вкладка **Actions**, около 5 минут). Готовый файл `tarelka.apk` появляется в разделе **Releases** справа на главной странице репозитория.

## Как установить

1. Скачайте `tarelka.apk` и перешлите на телефон (например, в Telegram).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого приложения — разрешите.
3. Новые версии ставятся поверх старой, записи сохраняются.

## Где что лежит

- `app/src/main/assets/index.html` — само приложение (интерфейс и база продуктов).
- `app/src/main/java/.../MainActivity.java` — обёртка Android: открывает приложение, кнопка «Назад», копирование и отправка отчёта.
- `app/tarelka.keystore` — ключ подписи. Не удаляйте: без него новые версии не встанут поверх старой. Репозиторий должен оставаться приватным.

Записи хранятся только на телефоне. Раз в неделю делайте резервную копию: «Ещё» → «Резервная копия».
